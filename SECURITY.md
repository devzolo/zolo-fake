# Security policy

## Supported versions

Security fixes are provided for the latest release.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository:
open the **Security** tab, choose **Advisories**, then **Report a vulnerability**.
Do not open a public issue for an undisclosed vulnerability.

Include the affected version, backend, a minimal reproduction, and the impact.
You can expect an initial response within seven days. We will coordinate a fix
and disclosure before publishing details.

Generated fake values are not cryptographically secure and must not be used as
passwords, tokens, keys, or anonymized production data. That is an explicit
product boundary, not a vulnerability.
